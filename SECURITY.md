# Security

This is a single-user private integration, not a public multi-tenant MCP service.
Read [the threat model](docs/SECURITY.zh-CN.md) before connecting real project data.

Do not post credentials, project secrets, or exploit payloads containing personal
data in public issues. Contact the repository owner privately or use GitHub's
private vulnerability reporting feature if it has been enabled. No private
reporting endpoint is assumed to exist before repository creation.

Only 0.1.x is currently maintained in this initial source release. This is not an
OpenAI-certified application and automatic scanning cannot guarantee zero leaks.
